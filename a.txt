2️⃣ Problèmes fréquents pour ce endpoint
🔴 a) Mauvais paramètre sort

Tu envoies :

sort=string


➡️ Spring attend normalement :

sort=field,asc


Essaie :

curl -X GET \
"http://localhost:8080/awsodclearning/api/admin/reports/audit/logs?page=0&size=1&sort=timestamp,desc"

🔴 b) Repository mal configuré

Souvent l’erreur vient de :

findAll(Pageable pageable)


ou

@Query(...)


Colonne inexistante

Mauvais mapping Entity

Date mal parsée

🔴 c) Problème avec les dates

Tu as :

startDate
endDate


Si ton code parse LocalDate :

LocalDate.parse(startDate)


➡️ Il faut format :

2025-01-09

🔴 d) Mauvaise gestion des filtres optionnels

Si tu fais :

if(action.equals("LOGIN")) { ... }


➡️ mais action = null → NullPointerException

Solution :

if("LOGIN".equals(action)) { ... }
